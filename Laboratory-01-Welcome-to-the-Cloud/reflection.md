# Reflection

This laboratory activity helped me understand the basic Linux
environment used in cloud computing. I learned how to navigate the
file system, create and manage users, and gather system information
using Linux commands.

I also learned the importance of organizing technical documentation
and maintaining a GitHub repository. These skills will be useful in
future cloud computing laboratory activities because they provide a
structured way to document my work and track my progress.

Overall, this activity gave me a basic foundation in Linux and cloud
computing environments.
