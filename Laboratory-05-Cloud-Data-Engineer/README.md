# Laboratory 5: The Cloud Data Engineer

## Mission Overview

As a member of the Cloud Data Engineering Team at CloudNova Technologies, I deployed a proof-of-concept S3-compatible object storage server using MinIO and Docker. The goal was to give a photo-sharing client a place to store user-uploaded images outside of ephemeral web server containers. I created a bucket named `client-photos` and uploaded a test file through the MinIO web console.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server (MinIO) using Docker.
- Access a cloud service via a web interface using port forwarding.
- Create a storage bucket and upload objects (files) to the cloud.
- Document cloud storage operations using Markdown.
- Continue expanding a professional GitHub Cloud Computing Portfolio.

## Tools Used

- KillerCoda Playground (Ubuntu)
- Docker
- MinIO (S3-compatible object storage)
- Git and GitHub
- Markdown
- Web browser

## Skills Learned

- Comparing block, file, and object storage and choosing the right one for a use case
- Deploying a containerized service with environment variables
- Mapping ports and accessing a service through a web console
- Creating buckets and uploading objects
- Writing clear technical documentation in Markdown
- Managing a structured GitHub portfolio with regular commits
