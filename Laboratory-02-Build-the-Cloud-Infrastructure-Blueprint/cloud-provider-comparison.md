# Cloud Provider Comparison

## Comparison Table

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | EC2 | Virtual Machines | Compute Engine |
| Storage | S3 | Blob Storage | Cloud Storage |
| Networking | VPC | Virtual Network (VNet) | Virtual Private Cloud (VPC) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID | Google Cloud IAM |

## Guide Questions

**1. Which cloud provider offers the broadest range of services? Explain your answer.**
AWS offers the broadest range of services, with over 200 tools spanning compute, storage, databases, AI, and networking. It was the first major cloud provider and has continued to expand its catalog to cover almost any use case a business might need.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?**
Microsoft Azure would be the best choice for such an organization because it integrates tightly with Microsoft's ecosystem, including Active Directory, Office 365, and .NET applications. This makes it easier to manage identity, licensing, and workflows for teams already using Microsoft tools.

**3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?**
Google Cloud Platform is widely recognized for AI/ML and Kubernetes, largely due to its TPUs (Tensor Processing Units), BigQuery ML, and GKE (Google Kubernetes Engine), which is considered one of the most mature managed Kubernetes services available.

**4. What similarities did you observe among the three cloud providers?**
All three providers offer equivalent core services—compute, storage, networking, and identity management—even though the names differ. Each also follows a pay-as-you-go pricing model and provides tools for scaling infrastructure and securing resources through IAM.
