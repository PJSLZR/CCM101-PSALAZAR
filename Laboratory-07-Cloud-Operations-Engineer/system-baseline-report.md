# System Baseline Report

## Memory (RAM)

## Disk Storage

Total storage capacity of the root (/) file system: **19G**

## Why Disk Space Matters Before a Traffic Surge

Running out of disk space before a traffic surge is critical to check because a full disk can crash the application, stop logs from being written, and prevent the database from saving new data, taking the entire service down even if CPU and memory are otherwise fine.
