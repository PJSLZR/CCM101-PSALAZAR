# Reflection

**1. Which cloud platform impressed you the most?**
The cloud platform that impressed me the most is AWS. I like how it offers many services for computing, storage, databases, networking, security, and other cloud needs. I also find it useful that AWS can support both small projects and large business systems.

**2. What similarities exist among AWS, Azure, and GCP?**
AWS, Azure, and GCP have many things in common. All three provide virtual machines, storage, databases, networking, security, identity management, and Kubernetes services. They mainly differ in the names of their services, features, pricing, and the areas where each platform is strongest.

**3. How do business requirements influence cloud platform selection?**
Business requirements help determine which cloud platform is the best choice. A company needs to consider its budget, applications, security needs, performance, and expected growth. For example, a company that already uses many Microsoft products may find Azure more convenient, while a company working with AI and large datasets may benefit more from GCP.

**4. What did you learn from acting as a Cloud Solutions Consultant?**
I learned that choosing a cloud provider requires more than simply selecting the most popular platform. I need to understand the client's goals, budget, current technology, and future plans first. I also learned how to compare cloud services and match them with different business situations.

**5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?**
My GitHub Cloud Computing Portfolio has improved because I was able to document my Linux investigation, cloud research, comparisons, and client recommendations. It now shows my understanding of AWS, Azure, and GCP. I think this makes my portfolio more useful because it shows not only what I learned about cloud computing but also how I can apply that knowledge to real situations.
