# AWS Research

## Brief Overview
Amazon Web Services or AWS is a cloud computing platform created by Amazon. It allows users to access computing resources and other IT services through the internet instead of managing all the hardware themselves. AWS can be used for applications, websites, databases, file storage, data processing, and many other technology needs. It is commonly used by both small developers and large companies.

## Global Infrastructure
AWS has data centers located in different parts of the world. These locations are organized into Regions, which contain multiple Availability Zones. This setup helps applications remain available even when problems occur in one location. Businesses can also select a region that is closer to their customers to help improve performance and reduce network delay.

## Cloud Management Console
The AWS Management Console is a website that provides a graphical interface for using AWS services. Instead of entering commands, users can click through menus to create and configure cloud resources. It can also be used to view resources, check service status, manage access, monitor usage, and review costs.

## Four Important AWS Services

1. **Amazon EC2** — EC2 provides cloud based computing capacity. Users can launch virtual servers and choose resources based on the requirements of their applications.
2. **Amazon S3** — S3 is designed for storing objects such as photos, videos, documents, backups, and application files. The stored data can be accessed when needed.
3. **Amazon VPC** — VPC provides a virtual network environment for AWS resources. It allows users to control network settings such as IP addresses, subnets, routing, and security rules.
4. **AWS IAM** — IAM controls who can access AWS resources and what actions they are allowed to perform. It is useful for managing users, groups, roles, and permissions.

## Three Advantages of AWS

1. **Flexible Resources** — AWS allows users to select resources based on their needs. They can increase or decrease computing capacity as their workload changes.
2. **Reliable Infrastructure** — AWS uses multiple regions and availability zones, which can help organizations build applications that are more reliable and resistant to infrastructure problems.
3. **Many Available Tools** — AWS offers a large collection of services for different purposes. Users can combine services to create solutions for computing, storage, networking, databases, security, analytics, and more.

## Typical Enterprise Use Cases
Companies can use AWS for many different tasks, including:
- Hosting company websites and online applications
- Running business software and APIs
- Storing important files and backup data
- Managing databases and business information
- Building development and testing environments
- Processing and analyzing large datasets
- Creating systems for backup and disaster recovery
- Supporting applications that need to handle changing numbers of users
