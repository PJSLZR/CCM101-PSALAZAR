# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a cloud platform created by Microsoft that provides different online services for organizations, developers, and IT professionals. Instead of relying only on physical computers and servers, users can access computing power, storage, databases, networking, security tools, and development services through Azure. It is widely used by organizations that already work with Microsoft technologies.

## Global Infrastructure
Azure has data centers distributed across many countries and geographic areas. These locations are grouped into Azure regions, allowing organizations to choose where their cloud resources will operate. Having resources in different locations can help improve application performance and support business continuity. Companies can also select locations that are appropriate for their customers and data requirements.

## Cloud Management Console
The Azure Portal is the main web interface for managing Azure resources. Users can use it to create and configure services without needing to work entirely through command line tools. The portal also provides features for checking resource usage, monitoring applications, managing subscriptions, configuring security, and viewing information about cloud resources.

## Four Important Azure Services

1. **Azure Virtual Machines** — This service allows users to create virtual computers in the cloud. These machines can run operating systems such as Windows or Linux and can be used for applications, testing, and business workloads.
2. **Azure Blob Storage** — Blob Storage is designed for storing large amounts of data. It can hold files such as images, videos, documents, backups, and other unstructured information.
3. **Azure Virtual Network** — Azure Virtual Network creates a private networking environment for cloud resources. It allows administrators to organize network connections and control how different resources communicate with one another.
4. **Microsoft Entra ID** — Microsoft Entra ID is an identity and access management service. It helps organizations manage accounts and control which users can access applications and resources.

## Three Advantages of Azure

1. **Easy Microsoft Compatibility** — Azure works closely with Microsoft products such as Windows Server, Microsoft 365, and business applications. This can make cloud adoption easier for organizations already using Microsoft's ecosystem.
2. **Support for Hybrid Environments** — Azure can connect cloud resources with systems that are still running in an organization's own facilities. This gives companies more flexibility when moving their systems to the cloud gradually.
3. **Wide Range of Services** — Azure provides many services for computing, storage, networking, databases, artificial intelligence, security, and application development. Organizations can choose different services depending on their specific requirements.

## Typical Enterprise Use Cases
Organizations can use Azure for different business and IT requirements, such as:
- Hosting websites and business applications
- Running Windows and Linux virtual machines
- Managing employee accounts and access
- Storing company documents and backup files
- Connecting on premises systems with cloud resources
- Supporting enterprise software and databases
- Developing and testing new applications
- Running business workloads that require flexible computing resources
