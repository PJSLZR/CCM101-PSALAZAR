## Linux Investigation

### Operating System
Ubuntu 24.04.4 LTS

### CPU Information
Intel Xeon E312xx (Sandy Bridge, IBRS update), x86_64 architecture, 1 CPU core.

### Memory
1.9 GiB total RAM, with about 1.4 GiB available.

### Disk Space
19G total disk space on / (/dev/vda1), 5.4G used, 13G available (30% used).

## Cloud Migration Analysis

**If this Linux server were migrated to the cloud, which AWS, Azure, and GCP services could host it?**

If this Linux server were moved to the cloud, it could run on a virtual machine from AWS, Azure, or GCP. Amazon EC2 could be used on AWS, while Azure Virtual Machines could host the Ubuntu system on Microsoft Azure. For GCP, Compute Engine would be the suitable service for running the Linux server.

The server has limited resources, with only 1 CPU core, 1.9 GiB of RAM, and 19 GB of storage. Because of this, a small virtual machine would be enough for basic applications, testing, and learning. I would personally choose Google Compute Engine because its virtual machines can be configured according to the resources needed. It would also be a good way for me to practice managing Linux servers in a cloud environment.
