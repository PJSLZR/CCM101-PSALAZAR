## Guide Questions

### 1. Which cloud provider offers the broadest range of services?
I would say **AWS** because it provides a very wide collection of cloud services. Users can find options for servers, storage, databases, networking, security, analytics, and many other needs. Because of this, AWS can support both simple projects and larger business systems.

### 2. Which provider best integrates with Microsoft technologies?
**Microsoft Azure** is the best choice for Microsoft integration. Since Azure is developed by Microsoft, it works well with technologies such as Windows Server, Microsoft 365, and Microsoft Entra ID. Companies that already use Microsoft products can therefore have an easier time connecting their existing systems to the cloud.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
I would choose **Google Cloud** for this category. Google has strong experience in artificial intelligence, machine learning, data processing, and container technologies. Google Kubernetes Engine, or GKE, is also available for deploying and managing container based applications. These features make GCP a good platform for modern software projects.

### 4. Which cloud platform would you personally choose and why?
Personally, I would choose **AWS** for my cloud platform. At first, I considered GCP because of its AI and data tools, but AWS interests me because it has many different services that I can explore. Since I am learning cloud computing, having access to different types of services would help me understand areas such as virtual machines, storage, networking, databases, and security. I also think learning AWS would give me useful experience for future cloud related work.

## Overall Comparison

All three platforms provide similar basic cloud capabilities, but each one has areas where it stands out. AWS has a very broad service selection. Azure is a strong option for organizations already using Microsoft technologies. GCP is especially attractive for data analysis, AI, machine learning, and Kubernetes.

For me, comparing the three platforms shows that there is no single cloud provider that is automatically the best for every situation. The right choice depends on what an organization needs, what technologies it already uses, and what kind of applications it plans to run.
